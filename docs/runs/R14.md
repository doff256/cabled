## Version 1.0.0

- The app, installer, engine (`CMakeLists.txt`) and iPhone app (`MARKETING_VERSION`) are all 1.0.0. iPhone build 13.
- The wire protocol stays 0.1, so 1.0 apps talk to each other and to any 0.1 builds.
- Released by tagging `v1.0.0`. The Release workflow publishes the installer, IPA, SideStore source and hashes as the latest release. SideStore offers it as an update.

## Known limits in 1.0

- **Windows 11 only.** The Windows 10 DirectShow camera (R10) comes after 1.0.
- **CPU processing.** Scaling, cropping and adjustments run on the CPU. That's fine up to 4K30, and 4K60 with no adjustments; the GPU pipeline comes after 1.0.
- **SDR, no audio** (Q11, Q14).
- **The R12 app matrix** (Teams, Zoom, Meet, Discord, OBS colour and behaviour) is still for the owner to fill in. Fixes from it go into 1.0.x.
- **iPhone 17 Pro** hasn't been tested yet; only the iPhone Air has.
