# Runs R5 + R6: negotiation, lenses and zoom

## R5: quality negotiation (2026-11-21)
- **CAPS** from the phone (formats, codecs). **0.5 s link probe** at connect. **Negotiator** (`windows/src/engine/negotiator.*`, pure and unit-tested): the app's chosen size/fps + CAPS + link → camera format, codec, bitrate.
  - Exact size if the phone has it, else the smallest same-aspect format that covers it (no upscaling), else the largest. Never below the app's fps if any format can do it.
  - Bitrate from the video-pipeline table (25 Mbit/s at 1080p30, ~107 at 4K60), capped at 70% of the link. HEVC only when H.264 doesn't fit.
- **Renegotiation** when the app changes format (debounced 0.7 s). **Video off when nobody watches** (no app on the camera, no preview), so the phone's camera rests. New state **idle**.
- **HEVC** end to end (phone encodes, PC decodes). The phone **cuts bitrate on stalls** (-25%) and recovers +5% every 2 s.
- **Camera formats:** SD dropped (browsers now default to 720p), 4K60 and 1440p added, then **1080p120, 720p120, 720p240** (selftest measures exactly 120.0 fps).
- Errors stay on screen 5 s before the retry.
- **Owner test (iPhone Air):** works. 1440p in OBS works. The phone captures 4K for it (iPhones have no 2560×1440 mode) and the engine downsizes, which is sharper than upscaling.

## R6: lenses and zoom (2026-11-21)
- CAPS lists **every camera**: virtual multi-lens devices ("Auto", which switches lenses itself while zooming), each physical lens, and the front camera. Each has a zoom range, switch-over points and a `zoomScale`, so the PC shows iPhone-style zoom (1× = main lens, 0.5× = ultra wide).
- **Default:** the rear main camera inside the "Auto" device when the phone has one (D-26), so zooming out reaches the ultra wide without switching cameras.
- **CONTROL_SET** zoom (smooth ramp or jump). **CONTROL_STATE** reports the zoom and the physical lens in use. The PC remembers zoom per camera and restores it after reconnects and format changes.
- **App:** lens buttons (Auto / Main / Ultra Wide / Tele / Front), a logarithmic zoom slider, quick presets (0.5× 1× 2× 3×…), a live zoom readout and the active lens.
- Tests: negotiator picks the chosen camera's formats, labels and presets; the engine converts display zoom to device factors and reconfigures at once on a camera change. **52/52** Windows tests.

### Not done / later
- The CLI (`cabled-engine`) has no camera/zoom options. Use the app.
- Front camera output is not mirrored (correct for the other side of a call). A "mirror my preview" option comes with the R9 settings.
- Tele / ultra-wide *physical* cameras are listed too. "Auto" is usually the better choice.
