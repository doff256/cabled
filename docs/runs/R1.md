## Your test checklist

You need: this PC (Apple Devices is already installed), the iPhone Air and/or iPhone 17 Pro, and either your Mac (Xcode) or SideStore.

### A. Install the companion (pick one)
- **Mac / Xcode (fastest):** clone the repo, then:
  ```
  brew install xcodegen
  cd ios
  cp Config/Local.xcconfig.example Config/Local.xcconfig
  ```
  Edit `Local.xcconfig`: your Team ID (Xcode → Settings → Accounts) and a personal bundle ID such as `com.<you>.cabled`. Then run `xcodegen generate && open Cabled.xcodeproj`, choose your iPhone, and press Run. First time only: on the iPhone, go to Settings → General → VPN & Device Management → trust your developer certificate, and turn on Developer Mode if asked.
- **SideStore/AltStore (the path real users take):** download `Cabled-ipa` from the latest *iOS* run under GitHub Actions, unzip it, and open `Cabled.ipa` in SideStore → My Apps → +.

Please do both on at least one phone eventually. The SideStore path also checks the signing-expiry readout.

### B. Run the probe
Open the **Cabled** app on the iPhone and leave it in the foreground. Move the cable from the Mac to this PC. Unlock the phone. Then on this PC:

```powershell
.\build\bin\Release\cabled-probe.exe list
```
```powershell
.\build\bin\Release\cabled-probe.exe test --json r1-iphone-air.json
```

### C. What to note (fill in the results table below)
1. **Trust:** did `list` show the phone *before* you tapped "Trust This Computer"? Did `test` connect before trusting? (Only the first time a phone meets this PC can show this. Don't reset trust settings on purpose: that also resets location and privacy permissions.)
2. **Loopback:** did `test` connect with the app on "Loopback"? If it didn't, switch to "All interfaces" and try again.
3. **Local Network prompt:** did iOS ever ask "Allow Cabled to find devices on local networks?" With which setting?
4. **Throughput:** the "Phone → PC" number. iPhone Air with its cable. 17 Pro with a **USB 3** USB-C cable, and with a basic charging cable.
5. **`ConnectionSpeed`** in the `list` output (if Apple reports it).
6. **Background:** with `test` running, swipe to the home screen. What does the probe say? Reopen the app and run `test` again. Does it reconnect without replugging?
7. **Signing expiry** shown in the app and in the probe report (SideStore install only).

Send me the `r1-*.json` files, or just paste the "Link report" block.

## Decision impact
- Loopback works, no prompt → D-01 confirmed. The companion binds to loopback only, and the bind switch is removed in R3.
- Only "All interfaces" works → companion binds to all interfaces. Document the Local Network prompt in onboarding and re-check R-60 (we still never *use* Wi-Fi).
- Throughput below ~60 Mbit/s → 4K30 H.264 doesn't fit, and HEVC becomes the default on that phone (Negotiator in R5).
