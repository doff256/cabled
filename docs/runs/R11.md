# R11: installer, onboarding, diagnostics, releases

(R10, the Windows 10 DirectShow camera, comes after 1.0: see the roadmap.)

## What was built

- **Installer:** `installer/Cabled.iss`, Inno Setup (D-17), built by `windows/scripts/build-installer.ps1`. The output is `build\installer\Cabled-Setup-<version>.exe`, about 68 MB, self-contained.
  - Installs to `C:\Program Files\Cabled` and asks for admin once.
  - **Camera:** stops Frame Server so the camera DLL can be replaced in place; if that fails, the DLL is replaced at the next restart. COM-registers the DLL in HKLM. Then, using `cabled-vcam`, removes any earlier "Cabled Camera" (including dev installs) and creates it once for all users.
  - **Other files:** creates the camera's log folder with write access for services. Adds a Start menu entry. Ships `LICENSE.txt` and FFmpeg's licence.
  - **Uninstall:** removes the camera, the COM registration and the start-at-login entry, then asks whether to delete settings and presets.
  - Windows 11 only (build 22000+). Unsigned (D-25).
- **First-run setup guide:** shown on first start; the App page has "Show the setup guide again".
  - The steps are Apple's iPhone service → plug in and Trust → open Cabled on the iPhone → ready. Each step ticks itself off from the engine's live state.
  - When Apple's service is missing (Apple Devices, `127.0.0.1:27015`), it offers Apple Devices in the Microsoft Store, or iTunes for Windows without a Store.
  - "Start at login, in the tray" is ticked by default (D-20).
  - Includes the Shortcuts tip that opens Cabled on the phone automatically.
- **Diagnostics window:** App → Diagnostics.
  - Shows, live: state, iPhone model and iOS, companion version, signing expiry, thermal and battery, measured USB link, incoming video, GPU or CPU decode time, latency, frames, keyframe requests (a stand-in for drops), reconnects and camera output.
  - Includes the PC and iPhone log.
  - **Copy report** puts a text report on the clipboard. Nothing is sent.
- **Signing expiry (R-22, F18):**
  - The engine now passes the companion's expiry from HELLO through to the app.
  - Under 2 days left, the status line says how many hours remain and to refresh in SideStore.
- **iPhone names:** model identifiers become names, e.g. "iPhone Air" instead of `iPhone18,4`.
- **Releases (`.github/workflows/release.yml`):** pushing a tag `vX.Y.Z` does the following in public CI:
  1. Builds and tests the Windows side, and builds the installer.
  2. Builds the unsigned IPA.
  3. Writes the SideStore/AltStore source `apps.json` with `.github/scripts/sidestore_source.py`.
  4. Writes `SHA256SUMS.txt`.
  5. Publishes a GitHub pre-release with install notes.

  The source URL never changes: `https://github.com/doff256/cabled/releases/latest/download/apps.json`. A manual run (Actions → Release → Run workflow) builds everything without publishing.
- **README** rewritten for users: install on Windows, install the iPhone app with SideStore, privacy, building.
- **Side panel** widened to 360 px, so all five tabs fit (owner report on R9).
- **Installed on the dev PC:** Inno Setup 6.7.3, per user, via winget.

## Owner test checklist

1. **Installer:**
   1. Quit Cabled from the tray.
   2. Run `build\installer\Cabled-Setup-0.1.0.exe`, choosing More info → Run anyway, then allow UAC.
   3. Afterwards, check that the Start menu has Cabled, Camera and OBS list exactly one "Cabled Camera", and that video works.
2. **Setup guide:** it appears on first start of the installed copy. Each step should tick off as you go. To see step 1's buttons, stop the Apple Mobile Device service.
3. **Diagnostics:** App → Diagnostics. The numbers should move. Copy report and paste it somewhere to check it reads well.
4. **Upgrade:** run the installer again over the top. It should work, with Cabled still in the tray afterwards.
5. **Uninstall:** use Settings → Apps → Cabled → Uninstall. The camera should disappear from apps, and you should be asked about settings.
6. **Release:** when you're happy, push a tag, e.g. `git tag v0.1.0 && git push origin v0.1.0`. Then add the source URL in SideStore and install from it.

Note: after installing, `vcam-dev-install.ps1` still works for development, but it points the camera back at the Dev copy. Run the installer again to switch back.

## Results
