# Stack

## iPhone companion
| Area | Choice |
|------|--------|
| Language / UI | Swift, SwiftUI. Swift 5 language mode for now. Moving to Swift 6 strict concurrency is planned once the capture pipeline settles (R3–R5) |
| Project file | Generated by **XcodeGen** from `ios/project.yml`. The `.xcodeproj` isn't committed (D-27) |
| Frameworks | AVFoundation, VideoToolbox, Network.framework, CoreMotion |
| Third-party deps | **none** |
| Min OS | iOS 17 (proposed, Q11) |
| Build | Development: Xcode (latest stable) on the owner's Mac. Release: **GitHub Actions macOS runner** (public repo), unsigned `.ipa` |
| Tests | XCTest on the simulator in CI |
| Distribution | SideStore (recommended) / AltStore, through a published source `apps.json` |

## Windows engine and virtual camera
| Area | Choice | Licence |
|------|--------|---------|
| Language | C++20, MSVC (Visual Studio 2022/2026 Build Tools, v143+) | — |
| Build | CMake. FetchContent for the small deps (pugixml, nlohmann/json, GoogleTest). **vcpkg manifest** (`windows/vcpkg.json`, baseline 2026.10.16) for FFmpeg, found automatically from VS's bundled vcpkg / `VCPKG_ROOT` / CI (D-28). Our code uses the static CRT; FFmpeg DLLs use the dynamic one | — |
| COM / Win32 helpers | WIL (Windows Implementation Library) | MIT |
| Graphics | Direct3D 11 + HLSL compute/pixel shaders | — |
| Decode | FFmpeg **9.0.2: libavcodec + libavutil + libswscale** only, D3D11VA hwaccel, **dynamically linked, LGPL build** (no `--enable-gpl`, no x264/x265). swscale is the CPU conversion stand-in until the GPU pipeline (R7) | LGPL-2.1 |
| JSON | nlohmann/json | MIT |
| Plist (usbmux) | pugixml for XML plist | MIT |
| Virtual camera Windows 11 | Media Foundation, `MFCreateVirtualCamera`. Structure based on Microsoft Windows-Camera VirtualCamera sample | MIT (sample) |
| Virtual camera Windows 10 | DirectShow base classes (Windows SDK samples). Ideas from softcam | MIT |
| Face detection fallback | `Windows.Media.FaceAnalysis` (WinRT, built in) | — |
| Tests | GoogleTest | BSD-3 |

## Windows UI
| Area | Choice |
|------|--------|
| Language | C# / **.NET 10 (LTS)** |
| UI | **WinUI 3** (Windows App SDK), unpackaged, self-contained |
| Preview | `SwapChainPanel` fed by the engine's DXGI swapchain (no frame copies through managed code) |
| Interop | C ABI exported from cabled_core.dll, `LibraryImport` source-generated P/Invoke |
| MVVM | CommunityToolkit.Mvvm (MIT) |
| Tests | xUnit |

**Considered alternative:** all-C++ UI (Win32 + Direct2D, or Qt 6). It's lighter at runtime (no .NET), but building a polished Fluent UI takes noticeably longer, and Qt adds ~40 MB plus LGPL obligations. **C# WinUI 3 was accepted** (Q15).

## Packaging and CI
| Area | Choice |
|------|--------|
| Installer | Inno Setup 6 |
| CI | GitHub Actions: `windows-latest` (build, unit tests, fake-device integration tests), `macos-latest` (IPA build + XCTest) |
| Releases | GitHub Releases: Windows installer + `.ipa` + SideStore/AltStore source JSON |
| Signing | Windows: **none, ever** (D-25). SHA-256 hashes published. iOS: none (the user's free Apple ID through SideStore) |
| Licence | **MIT** (D-24). FFmpeg as LGPL DLLs. No GPL code copied |

## Runtime dependency on the user's PC
- **Apple Mobile Device Service** (from Apple Devices or iTunes). It's the only external prerequisite.
