# Cabled

Turn an iPhone into a high-quality **wired** webcam for Windows. Plug in a cable, open the app, and the camera works.

USB only. No Wi-Fi, no accounts, no subscriptions. The iPhone companion is sideloaded with a free Apple ID (SideStore or AltStore).

> **Status: early development (spike run R1).** Nothing here is usable as a webcam yet. See [docs/roadmap.md](docs/roadmap.md).

## Building

**Windows** (Visual Studio 2022/2026 Build Tools with the C++ workload, CMake 3.25+):

```
cmake -S windows -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

Tools land in `build/bin/Release/`.

**iPhone** (macOS with Xcode 16+ and [XcodeGen](https://github.com/yonaskolb/XcodeGen)):

```
brew install xcodegen
cd ios
cp Config/Local.xcconfig.example Config/Local.xcconfig   # set your Team ID + a unique bundle ID
xcodegen generate
open Cabled.xcodeproj
```

CI builds an unsigned `Cabled.ipa` on every push (Actions → iOS → artifacts). Install it with SideStore or AltStore.
