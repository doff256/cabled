# Cabled

Turn an iPhone into a high-quality **wired** webcam for Windows. Plug in a cable, open the app, and the camera works.

USB only. No Wi-Fi, no accounts, no subscriptions. The iPhone app is sideloaded with a free Apple ID (SideStore or AltStore).

> **Status: 1.0.** Up to 4K, 1080p120, auto-framing, lens and camera controls, image adjustments and presets. Windows 11 only for now. Known limits: [docs/runs/R14.md](docs/runs/R14.md).

## Install on Windows

Windows 11 is needed (the virtual camera uses Windows 11's camera system).

1. Download `Cabled-Setup-<version>.exe` from [Releases](https://github.com/doff256/cabled/releases).
2. Run it. Cabled isn't code-signed (on purpose: there's no company behind it), so Windows says
   **"Windows protected your PC"**. Choose **More info → Run anyway**, then allow the admin prompt.
   You can check the download against `SHA256SUMS.txt` on the release page.
3. Windows also needs **Apple's iPhone service**. If it's missing, Cabled's setup guide sends you to
   **Apple Devices** in the Microsoft Store (or iTunes, on Windows without the Store).

Apps then list **Cabled Camera**: Zoom, Teams, Meet in Chrome/Edge, Discord, OBS, the Camera app.

## Install the iPhone app

iOS 17 or later. Apple only allows apps outside the App Store through sideloading, which with a free
Apple ID means re-signing every 7 days. SideStore does that for you.

1. Set up [SideStore](https://sidestore.io) on the iPhone (its guide walks you through it, once).
2. In SideStore, go to **Sources → +** and add:
   `https://github.com/doff256/cabled/releases/latest/download/apps.json`
3. Install **Cabled** from that source. Updates appear there too.
4. Plug the iPhone into the PC, tap **Trust** if it asks, and open Cabled on the phone.

When the 7 days are nearly up, both the phone and the PC remind you to refresh it in SideStore.

Optional: open Cabled on the phone automatically when it's plugged in. In the Shortcuts app, add an
automation: **Charger → Is Connected → Open App → Cabled**, set to run immediately.

## Privacy

Video goes over the USB cable only. Neither app talks to the internet, collects anything or checks
for updates by itself. "Copy report" in Diagnostics copies text to the clipboard; nothing is sent.

## Building

**Windows** (Visual Studio 2022/2026 Build Tools with the C++ workload, CMake 3.25+, .NET 10 SDK). The
first configure builds FFmpeg through vcpkg (about 10 minutes).

```
cmake -S windows -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
dotnet build app\Cabled.App\Cabled.App.csproj -c Release
```

Installer (needs [Inno Setup 6](https://jrsoftware.org/isinfo.php)): `windows\scripts\build-installer.ps1`.

**iPhone** (macOS with Xcode 16+ and [XcodeGen](https://github.com/yonaskolb/XcodeGen)):

```
brew install xcodegen
cd ios
cp Config/Local.xcconfig.example Config/Local.xcconfig   # set your Team ID + a unique bundle ID
xcodegen generate
open Cabled.xcodeproj
```

CI builds an unsigned `Cabled.ipa` on every push (Actions → iOS → artifacts).

**Releases:** push a tag `vX.Y.Z`. The Release workflow builds the installer and the IPA, writes the
SideStore source and hashes, and publishes a GitHub release.
